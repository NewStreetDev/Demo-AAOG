# AAOG Frontend

Sistema de gestión integral para la Asociación de Agricultores Orgánicos de Grecia (AAOG).

## Stack

- React 19 + TypeScript + Vite 7
- TanStack Query v5
- react-hook-form v7 + Zod v4
- Radix UI + Tailwind CSS v4
- Sonner, Lucide React, Recharts, React Leaflet

## Instalación

```bash
npm install
npm run dev
```

## Scripts

| Comando | Descripción |
|---|---|
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Build de producción (tsc + vite) |
| `npm run preview` | Preview del build |
| `npm run lint` | ESLint |

## Módulos

- **Mi Finca** — Información general, divisiones, plan general, plan anual
- **Agrícola** — Cultivos, cosechas, lotes, acciones agrícolas
- **Pecuario** — Ganado, apiario, salud, reproducción
- **Procesamiento** — Lotes de procesamiento
- **Finanzas** — Ventas y compras
- **Reglamentos** — Documentos normativos
- **Reportes** — Generación y análisis
